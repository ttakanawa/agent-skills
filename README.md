# Agent Skills

## Install

  ```bash
  npx skills add ttakanawa/agent-skills
  ```

  ```bash
  npx skills add ttakanawa/agent-skills --global
  ```

  ```bash
  npx skills add ttakanawa/agent-skills --skill commit-staged
  ```

## Uninstall

  ```bash
  npx skills remove ttakanawa/agent-skills
  ```

  ```bash
  npx skills remove ttakanawa/agent-skills --global
  ```

  ```bash
  npx skills remove commit-staged
  ```
